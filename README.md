# File Organizer CLI

CLI-інструмент на Node.js для аналізу директорій, пошуку дублікатів за хешами SHA-256, сортування файлів за категоріями та безпечного очищення застарілих даних.

## Встановлення та запуск

1. Клонуйте репозиторій та перейдіть у директорію проєкту:
   ```bash
   git clone <посилання-на-ваш-репозиторій>
   cd file-organizer
   ```

2. Встановіть залежності:
   ```bash
   npm install
   ```

3. Перевірте довідку команд:
   ```bash
   node file-organizer.js --help
   ```

```text
├── README.md           # Документація проєкту

    ├── scanner.js      # Клас Scanner: рекурсивний обхід і статистика файлів

    └── cleanup.js      # Клас Cleanup: пошук та видалення застарілих файлів
```

## Команди та приклади використання

Запускати команди можна як напряму через `node file-organizer.js`, так і через налаштовані npm-скрипти (`npm run <command> -- ...`).

### 1. `scan` — аналіз директорії
Рекурсивно сканує директорію та виводить загальну кількість файлів, сумарний розмір, статистику за типами файлів і віком, топ-3 найбільших файли та найстаріший файл.

* **Синтаксис:**
  ```bash
  node file-organizer.js scan <directory>
  ```
* **Приклад запуску:**
  ```bash
  npm run scan -- ./Downloads
  ```
* **Аргументи:**
  * `<directory>` — шлях до директорії для сканування (обов'язковий).

---

### 2. `duplicates` — пошук дублікатів
Обчислює криптографічний хеш SHA-256 для кожного файлу за допомогою потоків (`fs.createReadStream`), знаходить ідентичні файли з різними назвами та підраховує зайво витрачене місце.

* **Синтаксис:**
  ```bash
  node file-organizer.js duplicates <directory>
  ```
* **Приклад запуску:**
  ```bash
  npm run duplicates -- ./Downloads
  ```
* **Аргументи:**
  * `<directory>` — шлях до директорії для пошуку дублікатів (обов'язковий).

---

### 3. `organize` — сортування по категоріях
Копіює файли у цільову директорію, розподіляючи їх по папках (`Documents`, `Images`, `Archives`, `Code`, `Videos`, `Other`). Оригінальні файли не видаляються. Файли розміром ≥ 10 MB копіюються потоково через `stream/promises` (`pipeline`). При збігу імен автоматично додається суфікс (`file(1).pdf`).

* **Синтаксис:**
  ```bash
  node file-organizer.js organize <source> --output <target>
  ```
* **Приклад запуску:**
  ```bash
  npm run organize -- ./Downloads --output ./Organized
  ```
* **Аргументи та опції:**
  * `<source>` — вихідна директорія з файлами (обов'язковий).
  * `-o, --output <target>` — цільова директорія для збереження відсортованих файлів (обов'язковий).

---

### 4. `cleanup` — видалення застарілих файлів
Знаходить файли, старіші за вказану кількість днів. За замовчуванням працює у безпечному режимі попереднього перегляду (**dry run**) без фізичного видалення.

* **Синтаксис:**
  ```bash
  node file-organizer.js cleanup <directory> --older-than <days> [--confirm]
  ```
* **Приклад попереднього перегляду (dry run):**
  ```bash
  npm run cleanup -- ./Downloads --older-than 90
  ```
* **Приклад фактичного видалення:**
  ```bash
  npm run cleanup -- ./Downloads --older-than 90 --confirm
  ```
* **Аргументи та опції:**
  * `<directory>` — директорія для очищення (обов'язковий).
  * `--older-than <days>` — мінімальний вік файлів у днях (обов'язковий).
  * `--confirm` — підтвердження остаточного видалення файлів (опціональний прапорець).

## Особливості реалізації
* **Подієво-орієнтована архітектура:** усі команди реалізовані як класи, успадковані від `EventEmitter`, що розділяє бізнес-логіку та відображення прогресу в консолі.
* **Робота з потоками (Streams):** для хешування (`crypto`) та копіювання файлів від 10 MB використовуються стріми, що запобігає переповненню оперативної пам'яті.
* **Обробка помилок:** усі операції з файловою системою захищені блоками `try...catch` із деталізацією кодів помилок (`ENOENT`, `EACCES` тощо).
